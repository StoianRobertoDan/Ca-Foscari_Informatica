Project schedule:
- Plan Schedule Management:
	- Establishment of policies, procedures, and documentation of the schedule.
- Processes:
	- Define Activities:
		- Defining and documenting the specifics actions required to produce deliverables.
	- Sequence Activities:
		- Documenting the order in which activities are performed.
	- Estimate Activity Duration:
		- Estimating the number of work periods required to complete activities given expected resources.
	- Develop Schedule: 
		- Creating a schedule model to facilitate project execution and control by analysing: 
			- Activity Sequence.
			- Duration.
			- Resource Requirements.
			- Schedule Constraints.
	- Control Schedule:
		- Monitoring project actual status and comparing it to project schedule baseline, and implementing change controls as required.
