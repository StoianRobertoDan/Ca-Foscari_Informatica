Knowledge Areas:
![[Pasted image 20250520234303.png]]
- The 10 areas:
	1. Project Integration Management.
	2. Project Scope Management.
	3. Project Schedule Management.
	4. Project Cost Management.
	5. Project Quality Management.
	6. Project Resource Management.
	7. Project Communications Management.
	8. Project Risk Management.
	9. Project Procurement Management.
	10. Project Stakeholder Management.
1. Project Integration Management:
	- Identifying the work of the project and coordinating and integrating the appropriate processes. 
	- Includes the processes and activities to Identify, Define, Combine, Unify, and Coordinate the various processes and project management activities
	- ![[Pasted image 20250519233844.png]]
2. Project Scope Management:
	- Define and control what is and what is not part of the project.
	- ![[Pasted image 20250520010456.png]]
3. Project Schedule Management.
	- Estimating the duration of the project activities, defining a project schedule, and controlling deviations from the schedule.
	- ![[Pasted image 20250520010530.png]]
4. Project Cost Management:
	- Establish budgets and cost estimates for resources.
	- Keep costs control to stay within the approved budget.
	- ![[Pasted image 20250520010700.png]]
5. Project Quality Management:
	- Measure overall performance and monitor project results.
	- Compare them to the quality standards set out in the project-planning process.
	- Ensure that the customers will receive the product, service, or result they commissioned.
	- ![[Pasted image 20250520010843.png]]
6. Project Resource Management:
	- People management and personal interaction including leading, coaching, dealing with conflict, conducting performance appraisals.
	- ![[Pasted image 20250520010930.png]]
7. Project Communications Management:
	- Ensure that all project information is collected, organized, stored.
	- Ensure it is distributed to stakeholders, management, and project members at the proper time. 
	- When the project is closed, the information is archived and used as a reference for future projects.
	- ![[Pasted image 20250520011411.png]]
8. Project Risk Management:
	- Identifying, analysing, and planning for potential risks that might impact the project.
	- ![[Pasted image 20250520011455.png]]
9. Project Procurement Management:
	- Processes involved with purchasing goods or services from vendors, contractors, suppliers, and others outside the project team.
	- ![[Pasted image 20250520011552.png]]
10. Project Stakeholder Management:
	- Assess stakeholder needs, expectations, and involvement on the project.
	- ![[Pasted image 20250520011640.png]]
