[[4. Hypothesis testing#^6854a8||Hypothesis examples]]:
 - Test whether the mean connection speed is 54 Mbps:
	 - Two-sided alternative:
		 - $\begin{array}{lcr}H_{0}:\mu = 54 && \mbox{vs} && H_{A}:\mu \neq 54\end{array}$
 - Test whether the mean connection speed is lower than 54 Mbps:
	 - Left-sided alternative:
		 - $\begin{array}{lcr}H_{0}:\mu \geq 54 && \mbox{vs} && H_{A}:\mu < 54\end{array}$
		 - This is usually written as:
			 - $\begin{array}{lcr}H_{0}:\mu = 54 && \mbox{vs} && H_{A}:\mu < 54\end{array}$
 - Test whether the users has increased by more than 2000:
	 - Right-sided alternative:
		 - $\begin{array}{lcr}H_{0}:\mu_{2}-\mu_{1} \leq 2000 && \mbox{vs} && H_{A}:\mu_{2}-\mu_{1} > 2000\end{array}$
		 - This is usually written as:
			 - $\begin{array}{lcr}H_{0}:\mu_{2}-\mu_{1} = 2000 && \mbox{vs} && H_{A}:\mu_{2}-\mu_{1} > 2000\end{array}$
 - Test whether the proportion of defected items is at most 3% (else they are not accepted):
	 - Right-sided alternative:
		 - $\begin{array}{lcr}H_{0}:p \leq 0.03 && \mbox{vs} && H_{A}:p > 0.03\end{array}$
	 - This is usually written as:
		 - $\begin{array}{lcr}H_{0}:p = 0.03 && \mbox{vs} && H_{A}:p > 0.03\end{array}$
	 - The right-sided alternative is used here because:
		 - The null hypothesis need to be the "status quo" so in this case the items are accepted only if the proportion of the defected ones is equal or lower than 3%.
			 - This means that we cannot reject the initial hypothesis and the items are accepted.
		 - The alternative hypothesis represents the claim we need strong evidence to support so in this case only when the proportion of defected items goes over 3%.
			 - This means the evidence points to the fact that the proportion goes over the threshold, the null hypothesis is rejected and so are the items.

[[4. Hypothesis testing#^34cf0f||Z-test]]:
 - An internet provided is used to have a number of simultaneous users with a mean $\mu = 5000$ and a standard deviation $\sigma = 800$.
	 - After an upgrade the mean is $\bar{X} = 5200$ over number $n = 100$ random samples. Has the mean increased in a 5% significance level?
	 - Right-sided alternative:
		 - $\begin{array}{lcr}H_{0}:\mu = 5000 && \mbox{vs} && H_{A}:\mu > 5000\end{array}$
	 - Z-statistic: $Z = \frac{\bar{X}-\mu_{0}}{\frac{\sigma}{\sqrt{n}}} = \frac{5200-5000}{\frac{800}{\sqrt{100}}} = \frac{200}{80} = 2.5$
	 - Rejection region: $\mathcal{R} = [z_{0.05},\infty) = [1.64,\infty)$
	 - Duality theorem:
		 - $[\bar{X}-z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\bar{X}+z_{\alpha/2}\frac{\sigma}{\sqrt{n}}] = [5200-1.64(80),5200+1.64(80)] = [4868.8,5131.2]$ 
		 - The new mean $\mu = 5200$ is out of the acceptance region.
	 - Result:
		 - The Z-statistics is way over this value so the null statistics is rejected and it is accepted that the number of simultaneous users have increased over the 5% threshold.
 - Two manufacturer A and B produced respective 10 defective pieces on 500 samples and 12 defective pieces on 400. Can they be considered the same at 5% significance level?
	 - Two-sided alternative:
		 - $\begin{array}{lcr}H_{0}:p_{A}-p_{B} = 0 && \mbox{vs} && H_{A}:p_{A}-p_{B} \neq 0\end{array}$
	 - Standard error: $SE (\hat{\theta}) = \sqrt{\frac{p_{A}(1-p_{A})}{n_{A}}+\frac{p_{B}(1-p_{B})}{n_{B}}} = \sqrt{\frac{0.02(1-0.02)}{500}+\frac{0.03(1-0.03)}{400}} = \sqrt{0.0000392+0.00007275} = 0.01058$
	 - Z-statistics: $\frac{p_{A}-p_{B}}{SE(\hat{\theta})} = \frac{-0.01}{0.01058} = -0.945$
	 - Acceptance region: $\mathcal{A} = (-z_{\alpha/2},z_{\alpha/2}) = (-z_{0.05/2},z_{0.05/2}) = (-z_{0.025},z_{0.025}) = (-1.96,1.96)$
	 - The value of the Z-statistic is inside the significance level so the null hypothesis cannot be rejected.

[[4. Hypothesis testing#^a454a6||Z-test and MLE]]:
 - Simple random sample with continuous distribution with density: $f(x) = \theta(1-\theta)^{\theta-1}$ with $\theta>0 \;,\; x\in(0,1)$
	- Suppose sample size 300, the log-likelihood is: 
		- $l(f) = n\ln(\theta)+(\theta-1)\sum\limits_{i=1}^{n} ln(1-X_{i})$
		- We are given: $\sum\limits_{i=1}^{300} ln(1-X_{i}) = -291,4$
	- Test: $H_{0}: \theta = 1.2$ vs $H_{A}: \theta < 1.2$ with a $5\%$ significance level
	- Score function: $l'(f) = \frac{n}{\theta}+\sum\limits_{i=1}^{n} ln(1-X_{i}) = 0 \Rightarrow \hat{\theta} = - \frac{n}{\sum_{i=1}^{300} ln(1-X_{i})} = - \frac{300}{-291.4} = 1.03$
		- $\hat{\theta}$ is [[2. Estimation methods#^2ea646|| asymptotically normal]]: $\hat{\theta} \approx N(\theta,\mathcal{I}(\theta)^{-1})$
			- The normal distribution is $N(\mu,\sigma^{2})$
			- Variance: $Var(\hat{\theta}) = \sigma^{2} = \mathcal{I}(\theta)^{-1}$
	- Observed information: $\mathcal{I}(\theta) = J(\theta) = -\mathbb{E}[l''(f)] = -\mathbb{E}\left[- \frac{n}{\theta^{2}}\right] = \frac{n}{\theta^{2}}$
	- Z-statistic: $Z = \frac{\hat{\theta}-\theta_{0}}{\sqrt{Var(\hat{\theta})}} = \frac{\hat{\theta}-\theta_{0}}{\sqrt{\mathcal{I}(\theta)^{-1}}} = \frac{\hat{\theta}-\theta_{0}}{\sqrt{\frac{\theta^{2}_{0}}{n}}} = \frac{\hat{\theta}-\theta_{0}}{\frac{\theta_{0}}{\sqrt{n}}} = \frac{\sqrt{n}(\hat{\theta}-\theta_{0})}{\theta_{0}} = \frac{\sqrt{n}(\hat{\theta}-1.2)}{1.2}$ 
		- We use $\theta_{0}$ since our hypothesis $H_{0}$ sets $\theta$ to a specific value $\theta = \theta_{0} = 1.2$
	- [[4. Hypothesis testing#^de0ef7||Rejection Region]]: $\mathcal{R} = (-\infty, -z_{0.05}] = (-\infty, -1.64]$
	- Observed value: $z = \frac{\sqrt{n}(\hat{\theta}-1.2)}{1.2} = \frac{\sqrt{300}(1.03-1.2)}{1.2} = -2.45$
		- The value is out of the Acceptance Region and in the Rejection Region so we can reject it.
		- If we compute it using the estimated standard error since $\hat{\theta}\rightarrow\theta$ asymptotically we get: $z = \frac{\sqrt{n}(\hat{\theta}-1.2)}{1.03} = \frac{\sqrt{300}(1.03-1.2)}{1.2} = -2.86$
			- This gives us even stronger evidence against $H_{0}$.0
	- Alternative hypothesis: $Z = \frac{\sqrt{n}(\hat{\theta}-\theta_{A})}{\theta_{A}} = \frac{\sqrt{300}(1.03-1)}{1} = 0.52$
		- A random value of the alternative hypothesis is in fact inside Acceptance Region.

[[4. Hypothesis testing#^7387a8||Duality theorem]]:
 - Simple random sample (samples: 2.5, 7.4, 8.0, 4.5, 7.4, 9.2) from normal distribution with mean $\mu$ and standard deviation $\sigma = 2.2$.
	- Evaluate hypothesis system at the 5% significance level: $\begin{array}{lcr}H_{0}:\mu = 6 && \mbox{vs} && H_{A}:\mu \neq 6\end{array}$
		- This is a two-sided statistics, $\alpha = 0.05 \Rightarrow \alpha/2 = 0.025$.
			- $\mathcal{A} = (-z_{\alpha/2},z_{\alpha/2}) = (-1.96, 1.96)$
		- Estimator of $\mu$ is $\bar{X} = \frac{2.5+7.4+8.0+4.5+7.4+9.2}{6} = \frac{39}{6} = 6.5$
		- Z-statistic: $Z = \frac{\bar{X}-\mu_{0}}{\frac{\sigma}{\sqrt{n}}} = \frac{\sqrt{n}(\bar{X}-\mu_{0})}{\sigma} = \frac{\sqrt{6}(6.5-6)}{2.2} = 0.557$ 
			- The result of the null hypothesis is in the Acceptance region.
		- Using the duality theorem:
			- $\left|\frac{\bar{X}-\mu_{0}}{\frac{\sigma}{\sqrt{n}}}\right|>z_{\alpha/2} \Rightarrow |\bar{X}-\mu_{0}|>z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \Rightarrow$ $$\bar{X}-z_{\alpha/2}\frac{\sigma}{\sqrt{n}}<\mu_{0}<\bar{X}+z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$$
			- The confidence interval for $\mu$ is $[\bar{X}-z_{\alpha/2}\frac{\sigma}{\sqrt{n}},\bar{X}+z_{\alpha/2}\frac{\sigma}{\sqrt{n}}] = [6.5-1.96(0,898),6.5+1.96(0,898)] = [4.74,8.26]$
			- $\mu_{0} = 6$ is perfectly inside the confidence interval so the null Hypothesis cannot be rejected.
	- Evaluate hypothesis system at the 5% significance level: $\begin{array}{lcr}H_{0}:\mu = 7 && \mbox{vs} && H_{A}:\mu \neq 7\end{array}$
		- Acceptance region and estimator is still the same.
		- Z-statistics: $Z = \frac{\bar{X}-\mu_{0}}{\frac{\sigma}{\sqrt{n}}} = \frac{\sqrt{n}(\bar{X}-\mu_{0})}{\sigma} = \frac{\sqrt{6}(6.5-7)}{2.2} = -0.557$
			- This result is still inside the acceptance region so it cannot be rejected.
		- Using the duality theorem:
			- The interval is the same as before so $7\in[4.74,8.26]$, this means it cannot be rejected.

 - Two samples (50 each) of processes gave respective means 8.5 mins and 7.2 mins with the same (assumed) standard deviation of 1.8 mins.
	 - Two-sided alternative:
		 - $\begin{array}{lcr}H_{0}:\mu_{A}-\mu_{B} = 0 && \mbox{vs} && H_{A}:\mu_{A}-\mu_{B} \neq 0\end{array}$
	 - Standard error: $SE(\hat{\theta}) = \sqrt{Var(\hat{\theta})} = \sqrt{Var(\bar{X})+Var(\bar{Y})} = \sqrt{\frac{\sigma^{2}_{X}}{n}+\frac{\sigma^{2}_{Y}}{m}} = \sqrt{2\frac{\sigma^{2}}{n}} = \sqrt{2\frac{1.8^{2}}{50}} = \sqrt{0.1296} = 0.36$
	 - Z-statistics: $\frac{\bar{X}_{A}-\bar{X}_{B}}{SE(\hat{\theta})} = \frac{8.5-7.2}{0.36} = 3.61$
	 - Acceptance region with a significance level of 5%: $\mathcal{A} = (-z_{\alpha/2},z_{\alpha/2}) = (-1.96, 1.96)$
		 - The null hypothesis is rejected as it's Z-statistic is way over the 5% or 10%.
	 - To still accept the null hypothesis we need an extremely low significance level and the $Z$ results in a value that is far away from 0.
	 - [[4. Hypothesis testing#^4606cf|P-value]]:
		- $H_{0}$ is accepted only if $Z = 3.61 < z_{\alpha/2}$
		- Observed significance level: $p = \mathbb{P}(Z\geq 3.61) = 1-\Phi(3.61) = 0.0002$
			- This value is calculated by:
				- Cumulative distribution function of the standard normal distribution $N(0,1)$: $\Phi(z) = \int_{-\infty}^{z} \frac{1}{\sqrt{2\pi}}e^{-t^{2}/2}dt$
				- Using $pnorm(z)$ in R.
