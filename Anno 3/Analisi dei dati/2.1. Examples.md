[[2. Estimation methods#^275866|Maximum Likelihood]]:
 - Problem:
	 - A company claims its software has 80% accuracy, a tester has concluded that is 70% accuracy. On a test we get 11 correct cases on 15 tries.
		 - This is a binomial model.
	 - $L(\theta) = \binom{15}{11}\theta^{11}(1-\theta)^{4}$
		 - Company claims ($\theta=0.8$): $L(\theta) = \binom{15}{11}0.8^{11}0.2^{4} = 0.19$
		 - Tester claims ($\theta=0.7$): $L(\theta) = \binom{15}{11}0.7^{11}0.3^{4} = 0.22$
	 - Likelihood ratio: $\frac{L(0.7)}{L(0.8)} = \frac{\binom{15}{11}0.7^{11}0.3^{4}}{\binom{15}{11}0.8^{11}0.2^{4}} = \frac{0.7^{11}0.3^{4}}{0.8^{11}0.2^{4}} = 1.17$
		 - The tester's results are $17\%$ more likely.
 - Pareto Distribution:
	- Density: $f(x;\alpha) = \left\{ \begin{array}{ll} \frac{\alpha}{x^{\alpha+1}} & x>1, \alpha>1 \\ 0 & otherwise \end{array}\right.$
	- Likelihood for $\alpha$: $L(\alpha) = \alpha^{n}\prod_{i=1}^{n}X_{i}^{-(\alpha+1)}$
	- Log-likelihood: $l(\alpha) = n\ln(\alpha)-\alpha\sum\limits_{i=1}^{n}ln(X_{i})$ 
	- Score function: $l'(\alpha) = \frac{n}{\alpha}-\sum\limits_{i=1}^{n}ln(X_{i}) = 0$ 
	- Solution:
		- Since $l''(\alpha) = \frac{-n}{\alpha^{2}}<0 \,\,\forall \,\, a>1 \Rightarrow$
		- $\hat{a} = \frac{n}{\sum\limits_{i=1}^{n}\ln{X_{i}}}$

[[2. Estimation methods#^3d5b8a|Cramér-Rao inequity]] ($Var(\hat{\theta})\geq\mathcal{I}(\hat{\theta})^{-1}$):
 - [[4. Distribuzioni di variabili aleatorie discrete#^169d0b|Poisson]]:
	 - Distribution: $\mathbb{P} = \frac{\lambda^{k}}{k!}e^{-\lambda}$
	 - Variance: $Var(\lambda) = \frac{\lambda}{n}$
	 - Log-likelihood: 
		 - $l(\lambda) = -n\lambda+\ln\lambda\sum\limits_{i=1}^{n}X_{i}$
		 - $l'(\lambda) = -n+\frac{\sum X_{i}}{\lambda}$ (Score function)
		 - $l''(\lambda) = -\frac{\sum X_{i}}{\lambda^{2}}$
	 - Fisher information:
		 - $\mathcal{I}(\theta) = \mathbb{E}\{-l''(\lambda)\} = \mathbb{E}\left(\frac{\sum X_{i}}{\lambda^{2}}\right) = \frac{\sum\mathbb{E} (X_{i})}{\lambda^{2}} = \frac{\sum\lambda}{\lambda^{2}} = \frac{n\lambda}{\lambda^{2}} = \frac{n}{\lambda}$
		 - $\mathcal{I}(\theta)^{-1} = \frac{\lambda}{n} = Var(\lambda)$
 - [[4. Distribuzioni di variabili aleatorie discrete#^15e791|Bernoulli]]:
	- Distribution: $\mathbb{P} = p^{x}(1-p)^{1-x}$
	- Log-likelihood:
		- $l(p) = \ln(p)\sum\limits_{i=1}^{n}X_{i}+\ln(1-p)\left(n-\sum\limits_{i=1}^{n}X_{i}\right)$
		- $l'(p) = \frac{\sum X_{i}}{p}-\frac{n-\sum X_{i}}{1-p}$
			- $l'(p) = 0 \Rightarrow \hat{p} = \bar{X}$
		- $l''(p) = -\frac{\sum X_{i}}{p^{2}}-\frac{n-\sum X_{i}}{(1-p)^{2}}$
	- Standard Error:
		- $SE(\hat{p}) = \sqrt{Var(\hat{p})} = \sqrt{\frac{Var(X)}{n}} = \sqrt{\frac{p(1-p)}{n}}$
		- $\hat{SE}(\hat{p}) = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$
	- Observed Information:
		- $J(p) = -l''(p) = \frac{\sum X_{i}}{p^{2}}+\frac{n-\sum X_{i}}{(1-p)^{2}}$
	- Fisher Information:
		- $\begin{array}{ll}\mathcal{I}(p) = \mathbb{E}\{J(p)\} = \mathbb{E}\left(\frac{\sum X_{i}}{p^{2}}\right)+\mathbb{E}\left(\frac{n-\sum X_{i}}{(1-p)^{2}}\right) = \\ = \frac{\sum\mathbb{E}(X_{i})}{p^{2}}+\frac{n-\sum\mathbb{E}(X_{i})}{(1-p)^{2}} = \frac{\sum p}{p^{2}}+\frac{n-\sum p}{(1-p)^{2}} = \frac{n*p}{p^{2}}+\frac{n*(1-p)}{(1-p)^{2}} = \frac{n}{p(1-p)}\end{array}$
	- Asymptotic Standard Error:
		- $\hat{SE}(\hat{p}) = \mathcal{I}(\hat{p})^{-\frac{1}{2}} = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$
