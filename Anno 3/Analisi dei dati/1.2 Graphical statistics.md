Histograms:
- Histograms are graphs formed by adjacent columns.
	- The range of data is split into equal intervals ("bins") and the number of observations for each  interval is counted.
	- Each bin is expressed by a columns whose height is determined by the number of observations.
		- Frequency histogram:
			- When the height of the columns are determined directly from the number of observations.
		- Relative frequency histogram:
			- When the height of the columns are determined by the proportion with all the data.
