**Confidence Intervals**:
- Definition:
	- An interval $[a,b]$ is a $(1-\alpha)100\%$ **confidence interval** for a parameter $\theta$ if it contains the parameter with probability $(1-\alpha)$: $$\mathbb{P}\{a\leq\theta\leq b\}=1-\alpha$$
	- The *coverage probability* $(1-\alpha)$ is also called a **confidence level**.
