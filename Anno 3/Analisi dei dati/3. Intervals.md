**Confidence Intervals**:
 - Definition:
	- An interval $[a,b]$ is a $(1-\alpha)100\%$ **confidence interval** for a parameter $\theta$ if it contains the parameter with probability $(1-\alpha)$: $$\mathbb{P}\{a\leq\theta\leq b\}=1-\alpha$$
	- The *coverage probability* $(1-\alpha)$ is also called a **confidence level**.
	- The random interval $[a,b]$ is an **interval estimator** of $\theta$.
		- Endpoints $a,b$ are random variables (depend on data) and should be written as $[A(X_{1},\ldots,X_{n}),B(X_{1},\ldots,X_{n})]$, only after the sample is observed that we obtain a specific interval $[a,b]$ called **confidence interval estimate**.
		- 
 - Constructing confidence interval:
	 - Requirements of the estimator $\hat{\theta}$:
		 - [[1. Population, sample and notations^498016||Unbiased]] ($\mathbb{E}(\hat{\theta})=\theta$).
		 - Normally distributed ($\hat{\theta}\approx N\left(\theta,Var(\hat{\theta})\right)$)
	 - Standardized estimator: $Z = \frac{\hat{\theta}-\theta}{SE(\hat{\theta})}$
		 - Which follow the standard normal distribution $N(0,1)$.
		 - $Z$ is called Z-statistic.
	 - Quantiles of the standard normal distribution that define an area of $(1-\alpha)$:
		 - ![[Pasted image 20260615175807.png]]
		 - We need $(1-\frac{a}{2})$ quantile of the standard normal distribution: the $z_{\alpha/2}$ such that $\mathbb{P}(Z>z_{\alpha/2}) =\alpha/2$.
	 - Endpoints calculation:
		 - $\mathbb{P}\left\{-z_{\alpha/2}\leq\frac{\hat{\theta}-\theta}{SE(\hat{\theta})}\leq z_{\alpha/2}\right\} = 1-\alpha = \mathbb{P}\left\{\hat{\theta}-z_{\alpha/2}SE(\hat{\theta})\leq\theta\leq \hat{\theta}+z_{\alpha/2}SE(\hat{\theta})\right\}$
		 - $A = \hat{\theta}-z_{\alpha/2}SE(\hat{\theta})$ and $B = \hat{\theta}+z_{\alpha/2}SE(\hat{\theta})$
			 - Compact form: $\hat{\theta}\pm z_{\alpha/2}SE(\hat{\theta})$
	 - This is an interval centered at $\hat{\theta}$ with **margin of error** equal to $z_{\alpha/2}SE(\hat{\theta})$.
 - Approximate confidence levels:
	 - If the confidence interval approach is applied to an estimator that is asymptotically unbiased and asymptotically normal than the interval $\hat{\theta}\pm z_{\alpha/2}SE(\hat{\theta})$ has **approximately level** $(1-\alpha)$.
		 - The confidence level is approximate and the approximation improves as the sample size increases.
 - Sample size determination: ^b0c69f
	 - The margin of error ($z_{\alpha/2}SE(\hat{\theta})$) should be smaller than the given value $\triangle$: $ME\leq\triangle$
 - Confidence interval for the population mean:
	 - Natural unbiased estimator: $\hat{\mu} = \bar{X}$
	 - Normality (requirement):
		 - If $X_{1},\ldots,X_{n}$ are normal, then $\hat{\mu} = \bar{X}$ is normal.
		 - If $X_{1},\ldots,X_{n}$ are not normal but n is large, then $\hat{\mu} = \bar{X}$ is approximately normal.
			 - To know what n should be we need to solve the [[3. Intervals#^b0c69f||margin of error]] smaller than the given value: $z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\leq\triangle$
				 - This gives us $n\geq\left(\frac{z_{\alpha/2}\sigma}{\triangle}\right)^{2}$
		 - **Else** we **cannot** use Z-statistic.
	 - Standard error: $SE(\hat{\mu}) = \sqrt{Var(\hat{\mu})} = \sqrt{\frac{\sigma^{2}}{n}} = \frac{\sigma}{\sqrt{n}}$
	 - Confidence interval: $\bar{X}\pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$
 - Confidence interval of difference of means:
	 - Setting:
		 - $X_{1},\ldots,X_{n}$ with mean $\mu_{X}$ and known variance $\sigma^{2}_{X}$.
		 - $Y_{1},\ldots,Y_{m}$ with mean $\mu_{Y}$ and known variance $\sigma^{2}_{Y}$.
		 - Confidence interval to construct: $\theta = \mu_{X}-\mu_{Y}$.
	 - Assumptions:
		 - The random samples are independent.
		 - The populations are normal or the sample sizes $n$ and $m$ are large.
		 - Unbiased estimator: $\hat{\theta} = \bar{X}-\bar{Y}$
	 - Standard error: $SE(\hat{\theta}) = \sqrt{Var(\hat{\theta})} = \sqrt{Var(\bar{X})+Var(\bar{Y})} = \sqrt{\frac{\sigma^{2}_{X}}{n}+\frac{\sigma^{2}_{Y}}{m}}$
	 - Confidence interval: $\hat{\theta}\pm z_{\alpha/2}SE(\hat{\theta}) \Rightarrow (\bar{X}-\bar{Y})\pm z_{\alpha/2}\sqrt{\frac{\sigma^{2}_{X}}{n}+\frac{\sigma^{2}_{Y}}{m}}$
 - Unknown standard deviation:
	 - Large sample from any distribution:
		 - We expect $\hat{SE}(\hat{\theta}) \approx SE(\hat{\theta})$ so we construct a confidence interval with approximate level ($1-\alpha$) using the Z-statistic: $\hat{\theta}\pm z_{\alpha/2}\hat{SE}(\hat{\theta})$
			 - Population mean: $\hat{\mu}\pm z_{\alpha/2}\frac{\hat{\sigma}}{\sqrt{n}} \Rightarrow \bar{X}\pm z_{\alpha/2}\frac{S}{\sqrt{n}}$
			 - Difference of means: $(\hat{\mu_{X}}-\hat{\mu_{Y}})\pm z_{\alpha/2}\sqrt{\frac{\hat{\sigma}^{2}_{X}}{n}+\frac{\hat{\sigma}^{2}_{Y}}{m}} \Rightarrow (\bar{X}-\bar{Y})\pm z_{\alpha/2}\sqrt{\frac{S^{2}_{X}}{n}+\frac{S^{2}_{Y}}{m}}$
		 - **Confidence interval for proportions**:
			 - When we are interested in a specific population attribute $A$ we define it's proportion to the population: $p = \mathbb{P}(A)$
				 - Sample proportion: $\hat{p} = \frac{n_{A}}{n}$ where $n_{A}$ is the number of units with attribute $A$ in the sample.
				 - Can be also written as a Bernoulli distribution $X_{i}\sim Ber(p)$:
					 - $X_{i} = \left\{\begin{array}{ll}1 && \mbox{if unit }i\mbox{ possesses atttribute }A \\ 0&& \mbox{if unit }i\mbox{ does not possesses atttribute }A\end{array}\right.$
					 - Expected value: $\mathbb{E}[X_{i}] = p$
					 - Variance: $Var[X_{i}] = p(1-p)$
			 - Estimator of $p$ is the sample mean:
				 - $\hat{p} = \bar{X} = \frac{1}{n}\sum\limits_{i=0}^{n}X_{i}$
				 - Expected value: $\mathbb{E}[\hat{p}] = p$
				 - Variance: $Var[\hat{p}] = \frac{p(1-p)}{n}$
				 - It's **unbiased** and **asymptotically normal**: $\hat{p} = N\left(p, \frac{p(1-p)}{n}\right)$
				 - Estimated standard error: $SE(\hat{\theta}) = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} = \sqrt{\frac{\bar{X}(1-\bar{X})}{n}}$
				 - Confidence interval: $\hat{p}\pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}} \Rightarrow \bar{X}\pm \sqrt{\frac{\bar{X}(1-\bar{X})}{n}}$
		 - **Confidence interval for difference of proportions**:
			 - Assumptions:
				 - The random samples are independent with sizes $n_{1}$ and $n_{2}$.
				 - Confidence interval $\theta = p_{1}-p_{2}$ with estimator $\hat{\theta} = \hat{p_{1}} - \hat{p_{2}}$
			 - Standard error: $SE (\hat{\theta}) = \sqrt{\frac{p_{1}(1-p_{1})}{n_{1}}-\frac{p_{2}(1-p_{2})}{n_{2}}}$
			 - Estimated standard error: $\hat{SE} (\hat{\theta}) = \sqrt{\frac{\hat{p}_{1}(1-\hat{p}_{1})}{n_{1}}-\frac{\hat{p}_{2}(1-\hat{p}_{2})}{n_{2}}}$
			 - Confidence interval: $\hat{p}_{1}-\hat{p}_{2}\pm z_{\alpha/2}\sqrt{\frac{\hat{p}_{1}(1-\hat{p}_{1})}{n_{1}}-\frac{\hat{p}_{2}(1-\hat{p}_{2})}{n_{2}}}$
			 - [[3. Intervals#^b0c69f||Margin of error]]: $ME = z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\leq\triangle$
				 - $n\geq  \hat{p}(1-\hat{p})\left(\frac{z_{\alpha/2}}{\triangle}\right)^{2}$ 
					 - This expression depends on $\hat{p}$ which is not known before the sample collection.
					 - We can replace $\hat{p}(1-\hat{p})$ with $0.25$ (meaning $\hat{p}=0.5$, the maximum point in the function $\hat{p}(1-\hat{p})$)
