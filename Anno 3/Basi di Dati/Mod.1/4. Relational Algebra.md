The relational data model supports operations on the relations whose results are themselves relations.
These operations can be combined using an algebraic notation (*relational algebra*):
- **Fundamental Operations**:
	- **Rename**:
		- $\rho_{A_{1}\leftarrow B_{1},...,A_{n}\leftarrow B_{n}}(E)$
		- The result is a relation of type $\{(B_{1}:T_{1}, ..., B_{n}:T_{n})\}$ whose tuples are those of E with the attributes $A_{1},...,A_{n}$ renamed to $B_{1},...,B_{n}$.
	- **Project**:
		- $\pi_{A_{1},...,A_{n}}(E)$
		- The result is a relation of type $\{(A_{1}:T_{1}, ..., A_{n}:T_{n})\}$ whose tuples are those of E with only the attributes $A_{1},...,A_{n}$
		- Since the result is a set, any duplicate tuples are eliminated.
	- **Select**:
		- $\sigma_{<condition>}(E)$ 
		- The result is a relation with the same type as E, whose tuples are those of E which satisfy the condition.
	- **Set Union**:
		- $E_{1}\cup E_{2}$ 
		- The result is a relation with type as $E_{1}$ and $E_{2}$ (they have to be of the same type) whose tuples are those of $E_{1}$ or $E_{2}$ or both.
	- **Set Difference**:
		- $E_{1}- E_{2}$ 
		- The result is a relation with type as $E_{1}$ and $E_{2}$ (they have to be of the same type) whose tuples are those of $E_{1}$ but not of $E_{2}$.
	- **Product**:
		- $E_{1}\times E_{2}$ 
		- $E_{1}$ and $E_{2}$ are relations of type $\{(A_{1}:T_{1}, ..., A_{n}:T_{n})\}$ and $\{(A_{n+1}:T_{n+1}, ..., A_{n+m}:T_{n+m})\}$ with disjoint set of attributes.
		- The result is a relation of type $\{(A_{1}:T_{1}, ..., A_{n}:T_{n},A_{n+1}:T_{n+1}, ..., A_{n+m}:T_{n+m})\}$  whose tuples are all possible concatenations of tuples of $E_{1}$ and $E_{2}$.
- Additional Operations:
	- **Set intersection**:
		- $E_{1}\cap E_{2}$
		- The result is a relation with type as $E_{1}$ and $E_{2}$ (they have to be of the same type) whose tuples are those common of both $E_{1}$ and $E_{2}$.
	- **Join**:
		- $E_{1}\vartriangleright\vartriangleleft_{A_{i}=A_{j}}E_{2}$
		- Equivalent to $\sigma_{A_{i}=A_{j}}(E_{1}\times E_{2})$
		- $E_{1}$ and $E_{2}$ are relations of type $\{(A_{1}:T_{1}, ..., A_{n}:T_{n})\}$ and $\{(A_{n+1}:T_{n+1}, ..., A_{n+m}:T_{n+m})\}$ with disjoint set of attributes.
	- **Natural join**:
		- $E_{1}\vartriangleright\vartriangleleft E_{2}$
		- The natural join is only applicable when both $E_{1}$ and $E_{2}$ have attributes with the same name.
		- Note that:
			- If $E_{1}$ and $E_{2}$ have not common attributes $E_{1}\vartriangleright\vartriangleleft E_{2} \equiv E_{1} \times E_{2}$
			- If  $E_{1}$ and $E_{2}$ have the same type $E_{1}\vartriangleright\vartriangleleft E_{2} \equiv E_{1} \times E_{2}$
