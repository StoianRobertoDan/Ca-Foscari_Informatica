**SQL** (Structured Query Language) is the most used relational database language.
- **Data definition language** (DDL):
	- **Database**:
		- *CREATE DATABASE* is used to make a new schema, specifying the name and owner user. 
		- *DROP SCHEMA* is used to delete the schema.
	- **Table**:
		- *CREATE  TABLE* is used to make a new table inside the schema, specifying  the name, the attributes and constrains.
			- The primary key in MySQL can be written inline if only one attribute is part of the primary key. If multiple attributes are part of it, the form used is the one in the example below.
		- A table can be created on the results of a query using CREATE TABLE AS.
		- *ALTER TABLE* is used to modify a table.
		- *DROP TABLE* is used to delete a table.
	- **View**:
		- Views are virtual tables that can be queried as a normal table but does not physically exists in the database.
		- *CREATE VIEW* is used to make a view.
		- DROP VIEW is used to delete the table.

- **Modifying Relational Instances**:
	- **Insert**:
		- *INSERT* is used to add one or multiple records in a table.
		- *LOW_PRIORITY*:
			- The insert will be delayed until there are no processes reading from the table. 
		- *DELAYED*:
			- The inserted rows are put in a buffer until the table is available and the next SQL statement can be issued by the process.
		- *HIGH_PRIORITY*:
			- The insert will be given a higher priority overriding the database's "insert" priorities.
		- *ON DUPLICATE KEY*:
			- If specified and a row is inserted that would violate a primary key or unique index, an update will be performed instead of an insert or it will be ignored.
		- A query can be used for an insert instead of the list of attributes.
	- **Update**:
		- *UPDATE* is used to update existing records in a table.
		- A query can be used for an insert instead of the attributes.
	- **Delete**:
		- *DELETE* is used to delete one or multiple records from a table.
- **Access control**:
	- **Roles**:
		- Roles are named collection of privileges.
		- *CREATE ROLE* and *DROP ROLE* are used to make new roles and delete them.
		- *SET ROLE* is used to set the current user's privileges.
		- *SET DEFAULT ROLE* is used to set the default role to a specific set of privileges.
	- **User**:
		- *CREATE USER* is used to make a new user.
		- *GRANT* and *REVOKE* is used to change the access one or more users hold.
- **Data Manipulation Language** (DML):
	- **Select**:
		- *SELECT* is used to retrieve rows selected from one or more tables.
			- *AS* can be used to give aliases to attributes. The aliases can be used in *GROUP BY*, *ORDER BY* and *HAVING* clauses.
		- *FROM* is used to select in which table or tables to search for the rows.
			- *JOIN* can be used inside the *FROM* clause to joint together multiple tables.
		- *WHERE* is used to set one or more conditions that rows must satisfy to be selected.
		- GROUP BY is used to collect data across multiple records and group the results by one or more columns.
		- *ORDER BY* is used to sort the records of the result set.
		- Aggregation of data:
			- Normal return attributes and aggregation function can't be mixed together. To do so it is necessary to use the GROUP BY.
			- COUNT is used to count the values in a column of the query result.
			- SUM is used to sum the values in a column of the query result.
			- AVG is used to compute the average of the values in a column of the query result.
			- MIN and MAX are used to compute the minimum and maximum value in a column of the query result.
		- 
	- **Aggregation** of queries:
		- UNION is used to unite two queries. It is equivalent to $\cup$.
		-  INTERSECT is used to intersect two queries. It is equivalent to $\cap$.
		-  EXCEPT is used to subtract a query from another one. It is equivalent to $-$.
	- **Subqueries**:
		- Queries can be used in the SELECT, FROM or WHERE clause to increase the expressive power of SQL but are more complex and pron to errors.
- **Trigger**:
	- Triggers are used to automatize an action when INSERT, UPDATE or DELETE are executed.


```MYsql
/*Create database syntax*/
CREATE {DATABASE | SCHEMA} <name>
	<definitions>

/*Drop database syntax*/
DROP {DATABASE | SCHEMA} <name> [RESTRICT | CASCADE]

/*Create table syntax*/
CREATE TABLE <name> (
	<attribute_name> <data_type> [<constrains>],
	...
	[<table_constrains>]
);

/*Example of table creation*/
CREATE TABLE tab (
	id INTEGER,
	ref char(3) NOT NULL,
	PRIMARY KEY (id),
	FOREIGN KEY ref
		REFERENCES tab2(id)
		ON UPDATE [NO ACTION | CASCADE | SET NULL]
		ON DELETE [NO ACTION | CASCADE | SET NULL]
);

/*Alter table syntax*/
ALTER TABLE <name>
	ADD <attribute_name> <data_type> [<constrains>]
		[FIRST | AFTER <attribute_name>],
	DROP COLUMN <attribute_name>,
	MODIFY <attribute_name> <data_type> [<constrains>]
		[FIRST | AFTER <attribute_name>], 
	CHANGE COLUMN <old_attribute_name> <new_attribute_name> 
		<data_type> [<constrains>]
		[FIRST | AFTER <attribute_name>], 
	RENAME TO <new_name>;

/*Drop table syntax*/
DROP [TEMPORARY] TABLE [IF EXISTS]
	<table_name1>, <table_name2>, ...
	[RESTRICT | CASCADE];

/*Create view syntax*/
CREATE VIEW <name> AS
	<query>
	
/*Insert syntax*/
INSERT [LOW_PRIORITY | DELAYED | HIGH_PRIORITY] [IGNORE] 
	INTO <table_name> (<attribute_name1>, <attribute_name2>, ... )
	VALUES
		(<attribute1>, <attribute2>, ... ),
		... ,
	[ON DUPLICATE KEY [UPDATE | IGNORE] 
	    <duplicate_attribute1> = <expression1>,
	    <duplicate_attribute2> = <expression2>,
	    ...];

/*Update syntax*/
UPDATE [LOW_PRIORITY] [IGNORE] <table_name>
	SET <attribute_name> = <attribute>,
	    ... ,
	[WHERE <conditions>] 
	[ORDER BY <expression> [ ASC | DESC ]] 
	[LIMIT <number_rows>]; 

/*Delete syntax*/
DELETE [ LOW_PRIORITY ] [ QUICK ] [ IGNORE ] FROM <table_name>
	[WHERE <conditions>]
	[ORDER BY <expression> [ ASC | DESC ]]
	[LIMIT <number_rows>];

/*Create role syntax*/
CREATE ROLE [IF NOT EXISTS] <role> , ...;

/*Set default role syntax*/
SET DEFAULT ROLE 
	{NONE | ALL | <role> , ...} 
	TO <user> , ...;

/*Set role syntax*/
SET ROLE {DEFAULT | NONE | ALL | ALL EXCEPT <role> , ... | <role> , ...}

/*Create user syntax*/
CREATE USER [IF NOT EXISTS]
	<user_name> 
		[ IDENTIFIED BY <password>
		| IDENTIFIED BY RANDOM PASSWORD
		| IDENTIFIED WITH <plugin> [BY <password> | AS <password>]
		]
		[WITH <resource_option>]
		/* resource options:
		 MAX_QUERIES_PER_HOUR count 
		 MAX_UPDATES_PER_HOUR count
		 MAX_CONNECTIONS_PER_HOUR count
		 MAX_USER_CONNECTIONS count */
		[<password_option>]
		/* password options:
		 PASSWORD EXPIRE [DEFAULT | NEVER | INTERVAL <number> DAY]
		 PASSWORD HISTORY {DEFAULT | <number>}
		 PASSWORD REUSE INTERVAL {DEFAULT | <number> DAY}
		 PASSWORD REQUIRE CURRENT [DEFAULT | OPTIONAL]
		 FAILED_LOGIN_ATTEMPTS <number>
		 PASSWORD_LOCK_TIME {<number> | UNBOUNDED} */
		[ACCOUNT LOCK | ACCOUNT UNLOCK],
	...;	

/*Grant syntax*/
GRANT {<privilages> | ALL PRIVILEGES} [<attribute_name>, ...]
	ON {TABLE | FUNCTION | PROCEDURE} <privilage_level>
	TO {<user> | <role>}
	[WITH GRANT OPTION];

/*Revoke syntax*/
REVOKE [IF EXISTS] <privilage>, ... 
	ON {TABLE | FUNCTION | PROCEDURE} <privilage_level>
	FROM {<user> | <role>} 
	[IGNORE UNKNOWN USER];

REVOKE [IF EXISTS] ALL [PRIVILEGES], 
	GRANT OPTION FROM {<user> | <role>} 
	[IGNORE UNKNOWN USER];

REVOKE [IF EXISTS] <role>, ...
	FROM {<user> | <role>} 
	[IGNORE UNKNOWN USER];

/*Select syntax*/
SELECT 
	[ALL | DISTINCT | DISTINCTROW ] 
	[HIGH_PRIORITY]
	<expression>, ...
	[INTO {OUTFILE 'filename' <export_option> | DUMPFILE 'filename' | <var_name>}]
	[FROM <table> {JOIN <table> ON <condition>} | {NATURAL JOIN <table>}]
	[WHERE <condition>]
	[GROUP BY {<attribute> | <position> | <expression>}]
	[HAVING <condition>]
	[ORDER BY {<attribute> | <position> | <expression>} [ASC | DESC]]
	;

/*Create trigger syntax in MySQL*/
CREATE TRIGGER [IF NOT EXISTS] <trigger>
	{BEFORE | AFTER} {INSERT | UPDATE | DELETE}
	ON <table> FOR EACH ROW
	[{FOLLOWS | PRECEDES} <other_trigger>]
	<expressions>;

/*Create trigger in general SQL*/
{CREATE | REPLACE} TRIGGER <trigger>
	{BEFORE | AFTER} {SELECT | INSERT | UPDATE | DELETE}
	[OF <attributes>] ON <table>
	[REFERENCING {OLD | NEW} {ROW | TABLE} [AS <alias>]] 
	[FOR EACH {ROW | STATEMENT}]
	[WHEN <condition>]
	<expressions>;
```
